# DevOps Cloud Project

## Overview

This project demonstrates an end-to-end DevOps workflow for building, testing, containerizing, deploying, and monitoring an application.

The project will be developed incrementally to demonstrate practical DevOps engineering skills and cloud deployment practices.

## Project Goals

- Manage source code with Git and GitHub.
- Build and run an application using Docker.
- Automate testing and builds using GitHub Actions.
- Provision cloud infrastructure using Terraform.
- Deploy an application to Microsoft Azure.
- Explore Kubernetes deployment and management.
- Implement monitoring, logging, and security best practices.

## Planned Technology Stack

- **Version control:** Git and GitHub
- **Application:** Python
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Infrastructure as Code:** Terraform
- **Cloud platform:** Microsoft Azure
- **Container orchestration:** Kubernetes
- **Monitoring:** Prometheus and Grafana

## Development Approach

The project will be implemented in stages. Each stage will be tested and documented before proceeding to the next.

## Project Status

**Current stage:** Development environment setup and repository preparation.

**Status:** In progress.

## Learning Objectives

By completing this project, I aim to develop practical skills in version control, Linux, containers, automation, cloud infrastructure, deployment, monitoring, and troubleshooting.
